GitHub Releases & Update: https://github.com/EmFaisal-code/Studio-Download/releases

Aplikasi ini bersifat 100% PORTABLE tanpa perlu install:
1. Cukup double-click 'StudioDownload.exe' untuk menjalankan software.
2. FFmpeg sudah terintegrasi langsung di folder ini.
3. Riwayat unduhan (history.json) dan pengaturan (settings.json) tersimpan otomatis di folder ini.
4. Ekstensi browser ada di folder 'Extension'. Pasang di Chrome via chrome://extensions (Developer Mode -> Load Unpacked).
5. Ekstensi browser otomatis menyinkronkan cookies YouTube & stream URL ke aplikasi.
6. Untuk mengecek pembaruan versi terbaru, kunjungi: https://github.com/EmFaisal-code/Studio-Download/releases
