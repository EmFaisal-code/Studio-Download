# Session Log // 2026-09-20

## Rangkuman Permintaan Pengguna
1. **Perbaikan Kejelasan Perkiraan Ukuran File**:
   - Pengguna melaporkan: *"perkiraan ukuran dibuat lebih jelas, seperti yang ku lihat aku pilih yang 19gb tetapi pas didownload 4gb."*
   - Pada video *Arknights - Endfield 1.1* (1:14:50), kartu format 1440p tertera `~ 19.5 GB`, namun saat diunduh ukuran aslinya `~ 4 GB` (`3992.7 MB`). Kartu 144p bahkan tertera `~ 2.9 GB`.
2. **Pencatatan & Pembacaan Mandiri Menggunakan Skill Obsidian**:
   - Pengguna meminta: *"ingat sesi percakapan disini dengan mencatat menggunakan skill obsidian, aku ingin kau melakukan pencatatan secara mandiri dan membaca secara mandiri dengan catatan tersebut"*.

## Tindakan & Implementasi
1. **Investigasi & Koreksi Kalkulasi Ukuran File**:
   - Ditemukan bahwa YouTube menyajikan manifest HLS (`m3u8_native`, seri format `600`–`625`) dengan metadata `tbr` burst rate puncak (format `623` memiliki `tbr = 37.269 kbps`). Logika lama salah memilih format HLS dan mengalikannya dengan durasi video sehingga menghasilkan 19.5 GB.
   - Format DASH asli (`308` 1440p) sebenarnya hanya berukuran 3.90 GB + audio 69 MB = 3.97 GB.
   - Di `backend/parser.py`: Mengabaikan manifest HLS YouTube, memprioritaskan stream dengan byte riil dari server, dan menerapkan *sanity clamp* bitrate wajar.
   - Di `backend/downloader.py`: Menggunakan fungsi `format_bytes()` dinamis sehingga antrean menampilkan `[46.8 MB / 3.97 GB]` (bukan `3992.7 MB`).
   - Di `ui/components/format_cards.py`: Menambahkan tooltip detail ukuran gabungan video + audio.
2. **Pembentukan Memori Persisten Obsidian**:
   - Membangun struktur Obsidian Project Memory Vault lengkap di `notes/`:
     - `00_Index.md`: Indeks dan dashboard sentral.
     - `01_Architecture.md`: Diagram alur sistem dan modul.
     - `02_Decisions/`: 5 Architecture Decision Records (ADR-001 hingga ADR-005).
     - `03_Components/`: Dokumentasi 5 modul inti.
     - `04_Tasks.md`: Pelacakan roadmap dan milestone.
     - `05_Daily_Logs/`: Log harian dan kronologi sesi.
3. **Pembacaan & Verifikasi Mandiri**:
   - Melakukan pembacaan mandiri dari catatan yang telah dibuat untuk memvalidasi kesinambungan memori sistem.
4. **Implementasi Fitur Login "Who Are You", Mode Tamu (Guest), & Profil Personal**:
   - Menanggapi arahan pengguna mengenai prinsip pemisahan ruang privat dan publik: Software klien yang didistribusikan ke banyak pengguna dilarang menampilkan data orang lain maupun panel admin.
   - Mengeliminasi komponen `AdminDashboardDialog` dari antarmuka software publik.
   - Menggantikannya dengan `UserProfileDialog` (`ui/dialogs/profile_dialog.py`) yang murni menyajikan profil sesi milik pengguna itu sendiri, opsi ganti akun, dan mode tamu tanpa mengekspos data pengguna lain.
   - Menghapus fungsi penarikan seluruh database pengguna cloud ke client app.
   - Menyediakan skrip CLI admin privat terisolasi (`scratch/admin_cloud_users.py`) khusus bagi pengembang untuk memantau data Supabase dari terminal.
   - Menyusun catatan keputusan arsitektural [[ADR-006-User-Identity-Guest-Session-Admin-Dashboard|ADR-006: User Identity Onboarding, Guest Session, & Pemisahan Ruang Publik vs Privat]].
5. **Perbaikan Perkiraan Ukuran Terhadap Transkode & Eliminasi Karakter Titik (Bullet)**:
   - Menangani masalah perkiraan ukuran kartu format yang sebelumnya terkunci ("terpatok") hanya pada profil H.264.
   - Mengimplementasikan multi-codec parsing (`backend/parser.py`) yang menyimpan varian stream per resolusi (`compatible` / H.264, `original` / AV1, dan `prores` / Apple ProRes 422).
   - Menghubungkan dropdown `TRANSCODE` di `ui/main_window.py` sehingga mengganti pilihan langsung memperbarui kartu format secara real-time:
     - 1440p AV1 / Sumber Asli: otomatis tertera `~ 602.7 MB [AV1]`, selaras persis dengan ukuran unduhan asli 602.4 MB.
     - 1080p AV1 / Sumber Asli: otomatis tertera `~ 279.1 MB [AV1]`.
     - ProRes 422: otomatis tertera perkiraan ukuran master ProRes berbasis bitrate standar Apple.
   - Memastikan `backend/downloader.py` menggunakan `format_id` spesifik dari kartu format dan melakukan transcoding ProRes 422 jika profil ProRes dipilih.
   - Menghapus seluruh karakter titik bullet (`●` dan `•`) dari antarmuka (Title Bar, Status Cookies `[COOKIE_ACTIVE]`, kartu format, dan item antrean).
   - Mendokumentasikan ke dalam [[ADR-007-Transcode-Aware-Filesize-Estimation|ADR-007: Perkiraan Ukuran Dinamis Berbasis Transkode & Eliminasi Karakter Titik]].
6. **Koreksi Validitas Ukuran Kartu ProRes 422**:
   - Menyelaraskan perkiraan ukuran kartu ProRes 422 di `backend/parser.py` dengan ukuran unduhan stream YouTube riil (`prores_src_stream["total_filesize"]`).
   - Menghapus rumus bitrate teoritis uncompressed broadcast (yang menghasilkan angka membingungkan 57.39 GB untuk 1440p) sehingga angka kartu (~1.05 GB) kini selaras 100% dengan antrean unduhan riil yt-dlp (1.03 GB).
   - Menyesuaikan flag transcode FFmpeg di `backend/downloader.py` menggunakan profil standar Apple ProRes 422 (`-profile:v 2`) tanpa flag bloat `-bits_per_mb 8000`.
7. **Stabilitas Antrean Unduhan, Persistensi Logo, & Desain Ulang Notifikasi Ekstensi**:
   - Memperbaiki bug logo software kosong ("kadang kosong kadang ada") dengan menghubungkan `app_icon` langsung ke `MainWindow`, mengirim pesan Win32 `WM_SETICON` ke native HWND untuk taskbar/Alt-Tab, serta menyematkan logo resmi 18x18 pada `CustomTitleBar`.
   - Merombak notifikasi toast ekstensi browser (`extra/bg.js`) menjadi tema gelap cyberpunk/developer Studio Download (`#0c0d12`, aksen `#38bdf8`, tag `[STUDIO_DOWNLOAD] // INGEST_SENT`), serta mengeliminasi total emoji petir `⚡` dan format AI-slop.
   - Mengeliminasi total getaran ("geter-geter") pada list antrean unduhan: mengunci tinggi kartu pada 102px, menetapkan lebar minimum pada label statistik, mengisolasi pembaruan tombol agar `[ABORT]` tidak dihancurkan-ulang saat mengunduh, dan menerapkan pembatasan frekuensi (*throttling*) pada pemancar progress `downloader.py`.
   - Mendokumentasikan ke dalam [[ADR-008-UI-Stability-Logo-Persistence-and-Extension-Toast-Redesign|ADR-008: Stabilitas UI, Persistensi Logo, & Desain Ulang Toast Ekstensi]].
