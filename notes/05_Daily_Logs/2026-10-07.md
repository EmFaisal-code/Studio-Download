## Perbaikan Format Audio & Penambahan Fitur Unduh Ulang dari Riwayat (History)
1. **Permintaan Pengguna**:
   - *"perbaiki terkait pada audio, salah satu di select semuanya ke :active. lalu juga aku butuh fitur pada history, dimana dia menyimpan alamat link juga, jadi ketika di klik kita jadi bisa download lagi"*
   - Tangkapan layar memperlihatkan ketiga kartu preset audio (*MP3 320kbps*, *MP3 192kbps*, dan *M4A*) berstatus `[SELECTED]` secara bersamaan.

2. **Akar Masalah (Kartu Audio Terpilih Semua)**:
   - Pada pemetaan kartu format di [`ui/main_window.py`](file:///D:/Project/YT/ui/main_window.py), pencocokan kartu sebelumnya memeriksa:
     `card.format_data.get("height") == format_data.get("height") and card.format_data.get("format_id") == format_data.get("format_id")`.
   - Pada mode audio, preset format tidak memiliki atribut `height` maupun `format_id` (keduanya bernilai `None`). Akibatnya, perbandingan `None == None and None == None` selalu mengevaluasi ke `True` untuk setiap kartu audio yang diiterasi.

3. **Solusi & Implementasi**:
   - **Eksklusivitas Seleksi Kartu Format (`_is_format_match`)**:
     - Menambahkan fungsi pembanding cerdas [`_is_format_match`](file:///D:/Project/YT/ui/main_window.py).
     - Untuk mode audio, pencocokan dilakukan secara ketat berbasis `quality` (misal `"320"`, `"192"`, `"original"`) dan `format` (`"mp3"`, `"m4a"`).
     - Reset `self.selected_format = None` saat beralih mode video <-> audio sehingga default yang tepat langsung dipilih tanpa membawa state mode sebelumnya.
   - **Tampilan Tautan & Fitur Unduh Ulang pada Riwayat ([`ui/dialogs/history_dialog.py`](file:///D:/Project/YT/ui/dialogs/history_dialog.py))**:
     - Setiap entri riwayat kini menampilkan tautan video yang jelas (`🔗 [URL]`).
     - Tautan URL bersifat interaktif dan dapat diklik langsung untuk mengunduh ulang, dilengkapi tombol `[COPY]`.
     - Menambahkan tombol aksi khusus **`[RETRY] Unduh Lagi`** (`QPushButton.histBtnRedownload`).
     - Saat diklik, dialog riwayat memancarkan sinyal `redownload_requested(url)`, otomatis mengisi bilah input `_>_ URI` di jendela utama, dan langsung memicu analisis media `_on_analyze_clicked()` untuk siap diunduh kembali.
   - **Dukungan Sinkron di Web UI ([`frontend/app.js`](file:///D:/Project/YT/frontend/app.js))**:
     - Menambahkan baris tautan `🔗 ${item.url}` dan tombol `REDOWNLOAD` pada `renderHistory()` Web UI.

4. **Verifikasi**:
   - Unit test headless PySide6 memverifikasi bahwa:
     - Tepat 1 kartu audio yang terpilih saat pertama kali dibuka (MP3 320kbps).
     - Saat berpindah kartu (MP3 192kbps, M4A), hanya kartu yang diklik yang aktif (`is_selected == True`), sementara kartu lainnya nonaktif.
     - Sinyal `redownload_requested` pada `HistoryDialog` bekerja 100% dan mengisi URL input di jendela utama secara mulus.
