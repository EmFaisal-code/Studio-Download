# Log Sesi 2026-10-16 // Conversion Guard & Low-Disk Space Auto-Resume

## 1. Ikhtisar Sesi
Sesi ini mengimplementasikan solusi komprehensif untuk memastikan proses konversi file (transcoding Apple ProRes 422, remuxing TikTok audio/MKV, dan remuxing MP4/HLS) tetap berhasil dan tidak korup meskipun ruang penyimpanan di disk tidak mencukupi.

Sistem dilengkapi pemantauan ruang real-time, peringatan UI bertema kontras tinggi (`[STATUS:LOW DISK / PAUSED]`), penghentian sementara (*lossless pause*) berbasis penangguhan kernel Windows (`NtSuspendProcess`), pemantau latar belakang otomatis (*watcher thread*) yang melanjutkan konversi seketika saat ruang tersedia (`NtResumeProcess`), opsi pemicu manual `[CEK DISK]`, serta pencatatan audit log terperinci di `conversion_audit.log`.

---

## 2. Rincian Implementasi

### A. Modul Pelindung Konversi (`backend/conversion_guard.py`)
1. **Pemantauan Kapasitas Partisi**:
   - `get_path_disk_free(path)`: Mengembalikan ruang kosong aktual dalam byte menggunakan `shutil.disk_usage()`.
   - `get_drive_name(path)`: Mengidentifikasi drive letter target penyimpanan (misal `Drive D:`).
   - `format_bytes_human(bytes)`: Mengonversi byte ke representasi human-readable (`MB` / `GB`).
   - `MIN_SYSTEM_HEADROOM_BYTES = 300 MB`: Batas aman cadangan sistem agar OS Windows tidak membeku saat disk menipis.
2. **Penangguhan & Pelanjutan Proses Tingkat Kernel**:
   - `suspend_process(pid)`: Menggunakan `ctypes.windll.ntdll.NtSuspendProcess` (atau `SIGSTOP` di Linux) untuk menghentikan thread FFmpeg secara instan tanpa mengorbankan buffer pipeline atau frame yang telah diproses.
   - `resume_process(pid)`: Menggunakan `ctypes.windll.ntdll.NtResumeProcess` (atau `SIGCONT`) untuk melanjutkan proses secara mulus.
3. **Pencatatan Tugas Tertahan & Watcher Otomatis**:
   - `register_low_disk_paused_conversion()`: Mendaftarkan tugas yang tertahan karena ruang disk kurang dan mengembalikan `threading.Event`.
   - `DiskSpaceWatcher`: Thread daemon latar belakang yang memeriksa partisi tugas setiap 2.0 detik. Jika `free_bytes >= required_bytes + 300 MB`, ia secara otomatis memanggil `trigger_resume_for_task(task_id, is_manual=False)`.
4. **Pencatatan Audit Log**:
   - `log_conversion_audit()`: Mencatat setiap kejadian jeda, penangguhan proses, auto-resume, pengecekan manual, dan pembatalan ke berkas `conversion_audit.log`.

### B. Integrasi Engine Unduhan (`backend/downloader.py`)
1. **ProRes 422 Transcoder**:
   - Pengecekan sebelum konversi: Jika ruang tidak mencukupi, status beralih ke `paused` (`disk_low=True`), mencatat audit log, dan menunggu `resume_event`.
   - Pemantauan real-time in-flight: Di dalam loop `proc.stdout.readline()`, kapasitas disk diperiksa setiap 0.8 detik. Jika ruang turun di bawah ambang batas, proses FFmpeg ditangguhkan (`suspend_process`), checkpoint frame disimpan, dan thread menunggu hingga ruang dikosongkan.
2. **TikTok Audio & MKV Remuxing**:
   - Melakukan kalkulasi ukuran dan pengecekan kapasitas ruang disk sebelum konversi audio atau pengemasan kontainer dimulai.
3. **Generic Stream Remuxing**:
   - Melakukan pengecekan kapasitas sebelum pengemasan MP4 serta mendaftarkan subprocess ke `active_subprocesses` agar dapat ditangani secara aman.
4. **Kontrol Download Manager**:
   - `recheck_disk_and_resume(task_id)`: Memungkinkan pemicuan manual dari UI.
   - Peningkatan `cancel_download()` dan `resume_download()` untuk menangani tugas yang berstatus `disk_low`.
5. **Perbaikan Bug Unduhan TikTok (UnboundLocalError & Format Fallback)**:
   - Memperbaiki `UnboundLocalError: cannot access local variable 'sec_start' where it is not associated with a value` pada tahap post-processing `_download_tiktok` yang sebelumnya menyebabkan unduhan langsung TikWM gagal setelah file video selesai terunduh.
   - Mengisolasi penentu format yt-dlp agar tidak meneruskan ID format sintetis (`tiktok_original`, `tiktok_hd`) ke yt-dlp saat terjadi fallback, melainkan menggunakan `bestvideo+bestaudio/best`.

### C. Antarmuka Pengguna & Lokalisasi (`ui/components/task_item.py`, `backend/i18n.py`)
1. **Penyajian Kartu Tugas Visual**:
   - Status badge menyala: `[STATUS:LOW DISK / PAUSED]` dengan border `#f43f5e` dan latar `rgba(244, 63, 94, 0.15)`.
   - Telemetri disk ringkas: `[D: Sisa 142.0 MB / Butuh 4.2 GB]` dan pesan status `Waiting for disk space...`.
   - Tooltip diagnostik informatif yang merinci lokasi drive, sisa ruang, kebutuhan, dan panduan tindakan.
2. **Tombol Tindakan Pengguna**:
   - Tombol `[CEK DISK]` / `[CHECK DISK]` yang memicu sinyal `check_disk_clicked`.
   - Tombol `[GANTI FOLDER]` / `[STORAGE]` yang membuka jendela Pengaturan.
   - Tombol `[BATAL]` / `[ABORT]` untuk membatalkan unduhan secara aman.
3. **Kamus Internasionalisasi (`backend/i18n.py`)**:
   - Penambahan kunci terjemahan status dan tombol aksi untuk bahasa Indonesia (`id`) dan bahasa Inggris (`en`).
